# ScriptForge AI – YouTube Script Writer

Professional free YouTube script generator with daily limit protection.

## Features
- Full script package (Titles + Description + Tags + Script)
- Strong retention-focused structure
- 3 scripts per day limit per user (browser-based)
- Dark professional UI
- Mobile friendly

## Deploy on Netlify

1. Push this repo to GitHub
2. Connect the repo to Netlify
3. Add environment variable:
   - Key: `GEMINI_API_KEY`
   - Value: your free Gemini API key from https://aistudio.google.com/apikey
4. Deploy

Done!
